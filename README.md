# Gift of the Givers – ASP.NET Core Prototype

Academic prototype for Section C.

## Requirements covered

- ASP.NET Core MVC
- Responsive navigation and branding
- ASP.NET Core Identity authentication
- Employee and Donor roles
- Employee dashboard
- Relief project updates
- Volunteer registration
- One-time and recurring donation options
- ZAR, USD and EUR
- Mock payment method
- Placeholder donation receipt
- SQLite persistence

## How to run

1. Open `GiftOfTheGiversPrototype.csproj` in Visual Studio.
2. Make sure the .NET 8 SDK is installed.
3. Restore NuGet packages.
4. Press F5 or Ctrl+F5.
5. The SQLite database `giftgivers.db` is created automatically on first run.

The payment system is deliberately a mock for the academic prototype. Do not enter real card or banking details.
